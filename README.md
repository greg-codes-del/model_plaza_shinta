# Model Massa Plaza Shinta

Model 3D interaktif (three.js) untuk kasus Grand Final KEC 2026: optimalisasi aset LMAN Plaza Shinta, Karawaci, Kota Tangerang.

## Cara membuka

Buka `index.html` di browser. Tidak perlu instalasi; three.js r128 dimuat dari CDN, jadi perlu koneksi internet.

## Isi

- **Eksisting**: gedung 3 lantai (bentuk kotak, melebar di atrium), annex, dan lahan sekitar.
- **Tahap 1**: hub paket lantai dasar dengan Sewa Guna (2027–2031).
- **Tahap 2**: seluruh gedung dengan KSPd (2032–2061), tanpa annex; lahan bekas kolam dan lapangan dijadikan RTH (KDH 15%).
- **Rombak**: skenario cadangan bila uji kelayakan gedung gagal.
- **Interior**: denah lantai 1–3 sebelum dan sesudah, dari sketsa site visit November 2026.

Panel keuangan di tiap tab mengikuti model Excel tim (capex, IRR, NPV mitra).

## Catatan

- Ukuran massa diskalakan dari sketsa site visit, ±6.456 m² per lantai. Ilustratif, bukan gambar teknis.
- Label zona Tahap 2 masih memakai konsep hub paket; konsep pusat distribusi ritel belum dimasukkan ke model ini.
